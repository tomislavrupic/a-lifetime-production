# A Lifetime Production
A static cinematic archive for Back in My Days and its fictional making-of films, scandal report, and Gordy’s concerto.

Preview: `python3 -m http.server 8797`

Films are embedded from YouTube only after clicking Play. Character sheets and production artwork are local optimized derivatives of the approved project assets. No analytics or backend. Original production media remains outside this repository.

AI-generated poster and banners were created from project references on 2026-10-08. The first VHS mockup was superseded by the theatrical sci-fi cover at the creator's direction.

Screening room follows the public [WE ARE ALREADY HOME playlist](https://www.youtube.com/playlist?list=PLcf3nbUMZTNg). Last checked 2026-10-10: five videos. Update the static cards when public playlist entries change.
